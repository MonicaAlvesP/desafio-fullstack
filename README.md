# Gerenciador de Posts - Documentação Geral

Este repositório contém um sistema completo para gerenciamento de posts, composto por um **backend em Django** e um **frontend em Next.js**.

## 🔧 Tecnologias Utilizadas
- **Frontend**: Next.js, Sass, Axios
- **Backend**: Django
- **Banco de Dados**: PostgreSQL
- **Containerização**: Docker e Docker Compose

## ⚡ Como Rodar o Projeto

```bash
# Inicializar backend
cd backend
python manage.py runserver

# Inicializar frontend
cd frontend
npm run dev
```
